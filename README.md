# 声色片场

SillyTavern 角色卡。你到东京一家走下坡的老片商报到，挑一张招聘通知：当导演坐监视器后面，或者当男优上床。⚠️ NSFW，18+。

- `card.png` / `card.json`：角色卡（在线版），导入酒馆即可。片场脚本从这里的 `dist/pianchang.js` 经 jsDelivr 加载，作者修了 bug 刷新酒馆就是新的。
- `card-offline.png` / `card-offline.json`：离线版，脚本全部内嵌，不联网，也不会更新。
- `dist/pianchang.js`：片场脚本的完整代码。在线版按提交号从这里取，玩家能审到实际运行的代码。
- `changelog.md`：版本记录。

需要酒馆助手（JS-Slash-Runner），导入时允许角色脚本。
